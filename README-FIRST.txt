EVERQUEST RESEARCH & LOOT TOOL by Bromm

START HERE

1. Extract the ZIP.
2. Double-click START HERE.bat.
3. Choose Portable Mode or Desktop Mode.
4. The tool opens in your browser.

Portable Mode:
- No installation required.
- Your settings, loot history, sessions, Magelo profile names, and value overrides stay under portable-data\.

Desktop Mode:
- Creates a desktop shortcut.
- Stores working data in Windows AppData.
- If portable data exists, it offers to import it safely.
- Existing Desktop data is backed up first.
- Observed Loot History is merged, not overwritten.

EverQuest log:
- The tool tries to find a recently active eqlog_*.txt automatically.
- If there is more than one likely log, a normal Windows file picker opens in the most likely Logs folder.

Need help?
Run START HERE.bat and choose 3 - Check / Repair Setup.

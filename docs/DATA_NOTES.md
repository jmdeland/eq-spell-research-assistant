# Recipe Data Notes

The initial recipe pack is based on classic-era public research references and is intended as the engine-validation dataset, not the final Wayfarers Haven authority.

Critical modeling rules:
1. Prefer item IDs where multiple components share the same visible name.
2. Never classify an unknown `Words of ...`, `Rune of ...`, grimoire/writ/tome page, dissertation/thesis/compendium/memoir part, etched signet, or runed emblem as junk merely because it is absent from this pack.
3. Keep recipes external to application logic.
4. Allow server-specific overrides later.
5. Preserve subcombines such as faded page recovery as first-class recipes in the future dataset.
